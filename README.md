# uart_interfacing
<b>Project Overview</b>

This project implements a <b>UART (Universal Asynchronous Receiver/Transmitter) interface using Verilog HDL</b>. The design was developed to understand and implement serial communication at the RTL level.

The UART design supports serial data transmission (TX), serial data reception (RX), FIFO-based buffering, register-based control, and loopback operation. The design was first verified through simulation and was then implemented on a Basys 3 FPGA board using Xilinx Vivado.

<b>Objectives</b>

The main objectives of this project are:

> To understand UART serial communication.<br>
> To design UART transmitter and receiver using Verilog HDL.<br>
> To implement serial data transmission and reception.<br>
> To understand UART registers and control logic.<br>
> To implement FIFO-based data buffering.<br>
> To verify the design using simulation.<br>
> To implement and test the design on a Basys 3 FPGA.<br>
> To gain practical experience in RTL design, simulation, and FPGA implementation.<br>
